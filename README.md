# Analyse et débogage d'un projet C structurant une bibliothèque numérique (BLAS)

Ce TP présente l'analyse et le débogage d'un projet C structurant une bibliothèque numérique basée sur la BLAS (Basic Linear Algebra Subprograms).

## Objectifs
* Analyser le fonctionnement du code et sa structure.
* Compiler via Makefile.
* Utiliser des outils de débogage (GDB, Valgrind) pour identifier et corriger les erreurs.
